
# Wanderlust AI - 您的私人旅行精算师 🌍

## 项目愿景
Wanderlust AI 不仅仅是一个生成通用攻略的工具。我们的目标是解决旅行规划中最头疼的两个问题：**"带谁去？"** 和 **"钱够不够？"**。

大多数旅行APP只提供景点列表，而 Wanderlust AI 根据您的**具体同行人员**（如老人、儿童）和**硬性预算约束**（如 "2人1000元"）来倒推可行的行程。

## 🚀 核心功能亮点

### 1. 👥 用户画像深度定制
我们深知，带父母出行和情侣出游是完全不同的体验。
- **亲子模式**：AI 会自动过滤掉不适合推车的山路，增加动物园、科技馆等行程，并提示母婴设施。
- **长辈模式**：避免红眼航班和高强度特种兵行程，推荐老字号餐厅和舒适的休息点。
- **情侣/朋友模式**：专注于氛围感、拍照打卡和当地夜生活。

### 2. 💰 真实的预算精算
不再是模糊的“穷游”或“奢华”标签。
- **输入具体金额**：您可以直接告诉 AI：“我有 2000 元预算”。
- **动态分配**：AI 会实时搜索门票和酒店均价，计算出这 2000 元扣除硬性支出后，还能吃什么、玩什么。
- **超支预警**：如果您的预算不足以支撑您的梦想目的地，AI 会诚实地建议您调整天数或降低住宿标准。

### 3. 🔍 Google Search 实时落地
拒绝过时信息。每一次生成都经过 Google 实时搜索验证：
- **门票价格**：查询 2024/2025 最新票价（区分成人/长者/儿童票）。
- **避坑指南**：整合小红书、TripAdvisor 等平台的最新用户反馈（如“某景点正在装修”）。

## 🛠 技术实现
- **Prompt Engineering**: 使用了复杂的上下文 Prompt，要求 LLM 扮演“精算师”和“导游”的双重角色，严格执行 JSON 格式输出。
- **Google Search Tool**: 利用 Gemini 的 Tool Calling 能力，将生成式 AI 与实时互联网数据结合。
- **UI/UX**: React + Tailwind CSS 打造的沉浸式移动端体验，针对不同步骤设计了流畅的交互动画。

## 使用指南
1. 输入目的地和天数。
2. **关键步骤**：选择同行人员（这对行程影响巨大）。
3. **关键步骤**：输入您的总预算上限。
4. 选择您的住宿和交通偏好。
5. 等待 AI 为您生成一份包含详细价格估算的完美行程。
